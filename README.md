# 🧠 DocuMind AI

> AI-powered technical documentation generator for developers.

DocuMind AI transforms any codebase into clean, professional documentation in seconds using AI. Upload files, paste a GitHub repo, or drop a code snippet — and instantly generate production-ready docs, setup guides, API references, and project insights.

---

## ✨ Features

- 📘 Auto-generated README files  
- 🧭 Project overview & architecture insights  
- 🧱 Tech stack detection  
- 🧩 Function & file references  
- ⚙️ Setup and installation guides  
- 🛰️ API documentation generation  
- 🗂️ Project structure explanation  
- 🔧 Code improvement suggestions  
- 💯 Project health score  
- 🎯 AI-generated interview questions
- 
## 🌌 UI Highlights

- Interactive Three.js cosmic background  
- Glassmorphism dashboard  
- Smooth Framer Motion animations  
- Responsive across mobile and desktop
